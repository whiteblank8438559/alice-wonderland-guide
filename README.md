# 愛麗絲仙境旅行指南

以 Lewis Carroll《Alice's Adventures in Wonderland》原著為依據的繁體中文故事場景導覽網站。目前收錄第 7 章「瘋狂茶會」與第 8 章「皇后的槌球場」。

- [瀏覽網站](https://whiteblank8438559.github.io/alice-wonderland-guide/)
- [專案開發規則](AGENTS.md)

## 使用方式

從首頁點選場景卡片進入介紹頁，閱讀場景簡介、登場角色、故事特色、旅人筆記及原著依據，再按「返回首頁」繼續探索。

## 專案結構

- index.html：首頁及場景索引
- places/：各場景頁
- assets/css/style.css：全站共用樣式
- AGENTS.md：新增頁面與內容時的持續開發規則

本站為非官方、想像式導覽；人物與事件依原著整理，旅人筆記的創意延伸另有標示。網站使用靜態 HTML、CSS，不需後端或 API。
